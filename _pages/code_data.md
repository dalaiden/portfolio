# Particle filter code

<div>
<img src="assets/img/code.jpg" width="770" />
</div>

&nbsp;

Offline data assimilation code utilizing a particle filter: [https://github.com/dalaiden/DA_offline_PF](https://github.com/dalaiden/DA_offline_PF). The program has been employed in several recent publications ([Dalaiden et al., 2021](https://link.springer.com/article/10.1007/s00382-021-05879-6); [Dalaiden, Rezsöhazy et al., 2023](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2023GL104666)). For further details about the method, please refer to these publications. A video explaining the method and how we produced the Antarctic climate reconstructions: [https://youtu.be/3eY3XPmbZH8?si=VnWfFwemWJcWH47K](https://youtu.be/3eY3XPmbZH8?si=VnWfFwemWJcWH47K).

# Antarctic climate reconstructions

<div>
<img src="assets/img/fig_rec.jpg" width="770" />
</div>

&nbsp;

- **Latest reconstruction** from [Dalaiden, Rezsöhazy et al., 2023](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2023GL104666): [https://zenodo.org/record/7966208](https://zenodo.org/record/7966208). *The latest updated version of the Antarctic climate reconstruction. In comparison with the previous reconstruction, sea salt records from Antarctic ice cores are incorporated in the database.*
- Original reconstruction from [Dalaiden et al., 2021](https://link.springer.com/article/10.1007/s00382-021-05879-6): [https://zenodo.org/records/4770179](https://zenodo.org/records/4770179). *This reconstruction is based on a data assimilation method integrating water isotopic and snow accumulation from Antarctic ice cores in addition to Southern Hemisphere tree-ring width records*.
